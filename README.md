# 农行信用卡附属卡账单解析器

> [!CAUTION]
> **使用风险自负（Use at your own risk）**：本程序未经充分测试，可能解析出错、核对误判或与实际账单不符。请以银行官方渠道的数据为准，谨慎使用。

把农行金穗信用卡的电子对账单（`.eml`）解析成多份 xlsx（账务说明 / 交易明细 / 按卡汇总 / 每卡明细），并自动核对账务说明与交易明细是否一致。

## 获取 .eml 账单

QQ 邮箱 → 打开农行发来的「电子对账单」邮件 → 更多操作 → 导出为 `.eml` 文件。

## 命令行用法

1. 把 `.eml` 复制到 `bills/`，命名为 `bills/<期号>.eml`（期号如 `2608`）
2. 运行：

```bash
uv run main.py 2608
```

输出自动生成到 `bills/2608/`。核对不通过会直接报错。

## 网页版用法

浏览器打开：https://wintertee.github.io/abc-ebill/

上传 `.eml` 即可，处理完全在本地浏览器完成，数据不出本机。
